# AQI Dashboard

## Description
A real-time Air Quality Monitoring Dashboard built with Streamlit. This application displays live air quality data, pollutant levels, and 24-hour trends for major Indian cities. It utilizes APIs from WAQI (World Air Quality Index) and OpenWeather to fetch current and historical air pollution data, providing users with an interactive visualization of air quality metrics.

## Features
- **Live Data Display**: Real-time air quality metrics including PM2.5, PM10, NO2, SO2, CO, and O3 levels.
- **City Selection**: Choose from major Indian cities like Hyderabad, Delhi, Mumbai, Bangalore, Chennai, and Kolkata.
- **Interactive Map**: Visualize air quality on a map with color-coded markers based on AQI levels.
- **Pollutant Distribution**: Bar chart showing the distribution of various pollutants.
- **24-Hour Trend**: Line chart displaying PM2.5 and PM10 trends over the past 24 hours.
- **Auto-Refresh**: Dashboard automatically refreshes every 30 seconds to show the latest data.

## API Keys
This project requires API keys from:
- **WAQI API**: For real-time air quality data.
- **OpenWeather API**: For historical air pollution data.
